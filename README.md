# Lista-tareas_eQGuerrerosZ
## Descripción
Esta aplicación permite crear, organizar y dar seguimiento a tareas personales o escolares. El usuario puede agregar tareas, marcarlas como completadas, editarlas y eliminarlas. Elegí este mini-proyecto porque resuelve una necesidad simple y clara: no olvidar pendientes y poder ver el avance de forma ordenada. Su alcance es pequeño, así que es adecuado para una práctica inicial.

## User Stories
- Como usuario, quiero agregar una tarea para no olvidar pendientes importantes.
- Como usuario, quiero ver la lista de tareas para revisar lo que me falta por hacer.
- Como usuario, quiero marcar una tarea como completada para distinguir lo terminado de lo pendiente.
- Como usuario, quiero editar una tarea para corregir información.
- Como usuario, quiero eliminar una tarea para quitar pendientes que ya no necesito.
- Como usuario, quiero filtrar tareas pendientes y completadas para organizarme mejor.

## Metodología
**Ágil (Kanban)** — Elegí este enfoque porque el proyecto es pequeño, puede cambiar durante el desarrollo y conviene dividirlo en tareas cortas. El tablero Kanban permite ver de forma rápida qué está pendiente, qué está en proceso y qué ya se terminó.
